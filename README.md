# OICL AO PDF Desk

A simple reference tool for OICL Administrative Officers to download policy documents, proposal forms, and claim forms.

## Features

- 📚 **5 Policy Wordings** - Motor, Fire, Health, Miscellaneous, Aviation
- 📄 **5 Proposal Forms** - Motor, Fire, Health, Miscellaneous, General
- 📬 **5 Claim Forms** - Motor, Fire, Health, Miscellaneous, Checklist
- 📱 **Mobile Responsive** - Works on phone, tablet, desktop
- 🔗 **Direct Links** - All links go to official OICL website

## How to Deploy

### Step 1: Create New GitHub Repository

1. Go to GitHub.com
2. Click "+" icon (top right) → "New repository"
3. Repository name: `oicl-aodoc` (or any name you want)
4. Description: "OICL Administrative Officer PDF Reference Tool"
5. Click "Create repository" (public)

### Step 2: Upload Files

1. In the new repository, click "Add file" → "Upload files"
2. Upload these 2 files:
   - `index.html`
   - `_nojekyll`
3. Click "Commit changes"

### Step 3: Enable GitHub Pages

1. Go to repository "Settings"
2. Scroll to "Pages" (left sidebar)
3. Under "Source" select: "Deploy from a branch"
4. Select: "main" branch, "/" (root folder)
5. Click "Save"

### Step 4: Visit Your Site

After 2-3 minutes, visit:
```
https://YOUR-USERNAME.github.io/oicl-aodoc/
```

Replace `YOUR-USERNAME` with your GitHub username.
